Практическое руководство

Соберите и проверьте сайт

Используйте эту процедуру для обычного цикла редактирования, пересборки и перезагрузки либо для локальной статической сборки. Предполагается, что модель программы уже понятна; архитектурные объяснения находятся на страницах концепций.

Установите точные Web-зависимости

Перейдите в рабочее пространство Web-платформы и установите зависимости по сохранённому файлу блокировки без сценариев жизненного цикла пакетов.

Nushell · установка
cd web
^npm ci --ignore-scripts

Разрабатывайте с автоматической пересборкой и перезагрузкой

Для обычного редактирования запустите один долгоживущий процесс разработки вместо ручной пересборки и перезапуска сервера после каждого изменения.

Nushell · цикл разработки
^npm run dev

Команда использует тот же конвейер scripts/build.mjs, что и npm run build, следит за исходниками, контентом, страницами и статическими файлами Web-платформы, каноническими токенами Strata и семантическими диаграммами и перезагружает браузеры только после успешной сборки. Ошибка не завершает процесс наблюдения: исправление и сохранение запускают следующую попытку.

Автоматическая перезагрузка существует только в HTTP-ответах среды разработки: локальный сервер внедряет её, но код никогда не попадает в web/dist. Для остановки нажмите Ctrl+C.

Соберите статический сайт

Nushell · сборка
^npm run build
^npm run check:build

Сборка проверяет версионируемый реестр контента, добавляет навигацию и сведения о происхождении документации, визуализирует семантические диаграммы, создаёт метаданные обнаружения и записывает многостраничный сайт в web/dist. Затем проверка сборки проверяет обязательные результаты и бюджеты.

Запустите и проверьте готовую сборку

Nushell · локальный сервер
^npm run serve

npm run serve публикует существующий web/dist без пересборки и наблюдения. Откройте http://127.0.0.1:4173. Публичные маршруты берутся из реестра контента. Внутренняя лаборатория компонентов доступна для проверки, но исключена из публичной навигации и карты сайта.

Проверьте результат перед рецензированием

Сборка не является проверкой выпуска. До признания результата готовым к рецензированию выполните проверку Web-платформы.
