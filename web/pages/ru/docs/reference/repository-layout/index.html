Справочник

Структура репозитория

Это карта текущего репозитория для поиска сведений. Она описывает границы владения, а не обучает рабочему процессу.

Поверхности верхнего уровня

research.nu
Оркестрация Nushell для зарегистрированных исследовательских документов и воспроизводимых сборок.
ydmp/
Шаблоны, модели, заметки и вспомогательная инфраструктура исследовательского рабочего пространства YDMP.
design/
Канонические токены Pinega Strata, сгенерированные кроссплатформенные адаптеры, модели и компоновки Scientific Diagram Language, а также тесты дизайна.
web/
Статическая многостраничная Web-платформа, нативный HTML, Web Components, сценарии сборки, тесты и сгенерированный сайт.
docs/
Архитектурные, аудиторские и рабочие записи уровня репозитория, не являющиеся телами публичных Web-статей.
.github/workflows/
Проверки CI и процессы публикации артефактов проверки.

Рабочее пространство Web-платформы

web/pages/en/
Устойчивый английский семантический HTML; сборка сохраняет публичные URL без префикса.
web/pages/ru/
Устойчивый русский семантический HTML, публикуемый только под /ru/.
web/content/
Версионируемые логические записи контента, варианты локалей, данные обнаружения и зрелости, метаданные документации и каталоги сообщений интерфейса; текст статей здесь не хранится.
web/src/
CSS, Web Components с учётом локали и прогрессивным улучшением, а также общее клиентское поведение.
web/scripts/
Скрипты статической сборки, локального запуска и проверки сборки с учётом локали.
web/tests/
Модульные и архитектурные тесты, проверки в нескольких браузерах, проверки доступности и визуальных регрессий.
web/dist/
Сгенерированный результат, а не авторский источник.

Каноническое и сгенерированное

Нельзя смешивать канонический источник и сгенерированный результат. Токены Strata происходят из канонического источника и порождают адаптеры CSS, TypeScript и Typst; Web-текст происходит из нативного HTML и порождает страницы dist; записи обнаружения документации происходят из content-index.json и порождают проекции навигации, карточек и манифестов.

Если пути расходятся с документацией

Проверяйте текущее состояние репозитория и реестры контента и исследований, прежде чем считать старый путь действующим. Репозиторий авторитетен для существующих артефактов; принятые архитектурные записи задают предполагаемые границы.
