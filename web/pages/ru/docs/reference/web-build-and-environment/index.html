Справочник

Сборка Web-платформы и окружение

Точный текущий справочник команд и окружения Pinega Web. Для выполнения задачи от начала до конца используйте соответствующие практические руководства.

Набор инструментов

ПоверхностьТекущий контракт
Node.js>=26.0.0; CI фиксирует 26.7.0
Менеджер пакетовnpm с сохранённым package-lock.json
Playwright1.62.1
Контейнер браузеровmcr.microsoft.com/playwright:v1.62.1-noble, когда требуется совпадающий контейнер
Целевая сборкаСтатический многостраничный результат ES2022

Сценарии пакета

КомандаНазначение
npm run tokens:checkПроверить актуальность сгенерированных адаптеров токенов Strata.
npm run typecheckСтрогая проверка TypeScript без генерации результата.
npm run test:unitКонтракты дизайна, Web-архитектуры и контента.
npm run devЗапустить авторитетную статическую сборку в режиме наблюдения, публиковать web/dist и перезагружать браузеры после успешных пересборок.
npm run buildОдин раз создать статический сайт и служебные артефакты обнаружения.
npm run check:buildПроверить сгенерированный результат и бюджеты.
npm run serveПубликовать существующий web/dist без сборки и наблюдения.
npm run test:browserНабор браузерных тестов и тестов доступности для Chromium, Firefox и WebKit.
npm run test:visualЭталоны визуальных регрессий для настольного Chromium.

Область наблюдения при разработке

npm run dev следит за web/src/, web/content/, web/pages/, web/static/, design/tokens/, design/diagrams/ и генератором токенов Strata. События файловой системы объединяются с небольшой задержкой, а каждая пересборка вызывает тот же web/scripts/build.mjs, что и однократная сборка.

Успешная сборка публикует локальное событие Server-Sent Events и полностью перезагружает браузер. Ошибка оставляет процесс живым и не отправляет команду перезагрузки. Клиент автоматической перезагрузки внедряется только в HTTP-ответы среды разработки и не попадает в сгенерированный dist.

Сгенерированные результаты

  • web/dist/ — статический сайт с учётом локали.
  • site-manifest.json — проекция логических записей и локализованных вариантов.
  • content/en/documentation-manifest.json и content/ru/documentation-manifest.json — локализованные проекции документации для будущего поиска.
  • sitemap.xml и robots.txt — файлы обнаружения, полученные из флагов реестра.
  • assets/ — собранные CSS, JavaScript и ресурсы Web Awesome.

Бюджеты сборки

Текущая проверка сборки ограничивает суммарные бюджеты JavaScript и CSS. Авторитетны значения в web/scripts/check-build.mjs: это исполняемая политика CI, а не цель только в тексте.
