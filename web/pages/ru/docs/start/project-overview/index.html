Обзор проекта

Эта страница задаёт имена, зрелость и границы репозитория, необходимые для правильного понимания заявлений об архитектуре, исследованиях и производительности.

Модель программы

Pinega — зонтичная программа исследований, инженерии, технологий и будущих продуктов в области систем баз данных. Pinega Labs — её текущая исследовательская и инженерная идентичность и возможная идентичность будущей компании. Pinega Engine — первая активная программа реализации под этим зонтиком.

Эти имена намеренно не взаимозаменяемы. Исследования оптимизации запросов, верификации, распределённых систем или инженерии производительности могут относиться к Pinega, не являясь частью Pinega Engine.

Что существует сегодня

  • Версионируемое исследовательское рабочее пространство YDMP с шаблонами Typst и сохраняемыми исследовательскими артефактами.
  • Pinega Strata — общая кроссплатформенная дизайн-система.
  • Scientific Diagram Language с каноническими независимыми от визуализатора моделями и визуализаторами для Web и Typst.
  • Статическая многостраничная Web-платформа с метаданными контента, браузерными проверками, проверками доступности и тестами визуальных регрессий.
  • Принятые архитектурные решения и проверочные образцы Pinega Engine.

Чего пока не существует

Нет производственного бинарного Pinega Engine, клиентского развёртывания, производственного интерфейса SQL/TAM, проверенного пути персистентности или результата бенчмарка, достаточного для публичного заявления о производительности. Поэтому сайт использует метки исследования, решения и проектного контракта, а не язык доступности продукта.

Не выводите наличие реализации из описания архитектуры. Документированная граница может быть принята, хотя соответствующий производственный код остаётся будущей работой.
