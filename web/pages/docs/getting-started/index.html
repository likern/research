The former all-in-one Getting Started article has been decomposed. This page is now orientation only: it sends you to the smallest document that owns the question you are trying to answer.

Programme status: the current corpus documents research, architecture, and engineering-platform work. There is no production Pinega Engine installation procedure yet because no production engine release exists.

If you are new to Pinega

Begin with Project overview. It defines Pinega, Pinega Labs, Pinega Engine, the current repository artefacts, and the explicit boundary between what exists today and what remains proposed.

If your next goal is to reproduce real artefacts rather than read more explanation, continue with Reproduce the research workspace.

If you already know the goal

  • Build and inspect the website for the static Web workspace.
  • Run the Web validation gate for tests, browsers, accessibility, and visual regression.
  • Review and release gates before declaring a pull request ready.

If you need understanding rather than instructions

  • Pinega programme model for the master-brand and programme hierarchy.
  • Pinega Engine architecture for PostgreSQL integration, mutable versions, the buffer pool, and WAL.
  • Maturity and evidence labels for how public claims are classified.
  • Research-to-product workflow for the path from research evidence to measured software.

If you need exact lookup material

Use the Repository layout, Web build and environment, and Content metadata schema references. They are deliberately descriptive rather than tutorial-like.
