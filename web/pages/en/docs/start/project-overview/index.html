Project overview

Use this page to establish the naming, maturity, and repository boundary before interpreting architecture, research, or performance claims.

Programme model

Pinega is the umbrella database-systems research, engineering, technology, and future product programme. Pinega Labs is its working research and engineering identity and a plausible future company identity. Pinega Engine is the first active implementation programme beneath that umbrella.

The names are intentionally not interchangeable. Research on query optimisation, verification, distributed systems, or performance engineering can belong to Pinega without being part of Pinega Engine.

What exists today

  • A versioned YDMP research workspace with Typst templates and durable research artefacts.
  • Pinega Strata, the shared cross-platform design system.
  • Scientific Diagram Language with canonical renderer-independent models and Web/Typst renderers.
  • A static multi-page Web platform with content metadata, browser/accessibility gates, and visual regression tests.
  • Accepted architecture decisions and validation specimens for Pinega Engine.

What does not exist yet

There is no production Pinega Engine binary, customer deployment, production SQL/TAM interface, validated persistence path, or benchmark result that can support a public performance claim. The site therefore uses research, decision, and design-contract labels instead of product-availability language.

Do not infer implementation from architecture. A documented boundary may be accepted while the corresponding production code remains future work.
