## 1. Производственная постановка

**CONFIRMED — VANDERBEI.** Рассматривается один фиксированный момент времени.
Производственное предприятие мало относительно рынка и не может своими
действиями менять рыночные цены сырья или готовой продукции: оно является
`price taker`.

Обозначения:

- `i = 1, ..., m` — индекс вида сырья;
- `j = 1, ..., n` — индекс продукта;
- `b_i` — имеющийся запас сырья `i`;
- `rho_i` — текущая рыночная стоимость единицы сырья `i`;
- `a_ij` — количество сырья `i`, необходимое для производства единицы продукта `j`;
- `sigma_j` — рыночная цена единицы продукта `j`;
- `x_j` — число производимых единиц продукта `j`.

Для физической постановки эти величины неотрицательны. В частности,
`a_ij, b_i, rho_i, sigma_j >= 0` и `x_j >= 0`.

## 2. Производственный менеджер

**CONFIRMED — VANDERBEI.** Чистая выручка на единицу продукта `j` равна

```text
c_j = sigma_j - sum_{i in I} rho_i a_ij.
```

Модель распределения ресурсов:

```text
maximize    sum_{j in J} c_j x_j

subject to  sum_{j in J} a_ij x_j <= b_i    for every i in I,
            x_j >= 0                         for every j in J.
```

Ресурсное ограничение суммирует расход одного фиксированного сырья `i` по всем
продуктам `j`; поэтому `j` — связанный индекс суммы, а `i` — свободный индекс
строки ограничения.

### Почему стоимость уже купленного сырья вычитается

**INFERRED.** Пусть после производства весь остаток сырья продаётся по текущим
ценам. Тогда конечная выручка равна

```text
R(x)
  = sum_j sigma_j x_j
    + sum_i rho_i (b_i - sum_j a_ij x_j)
  = sum_i rho_i b_i + sum_j c_j x_j.
```

Первое слагаемое — рыночная стоимость исходного запаса; оно не зависит от `x`.
Поэтому оно меняет численное значение максимума, но не меняет оптимальный план:

```text
argmax_x (K + f(x)) = argmax_x f(x),
max_x (K + f(x)) = K + max_x f(x).
```

Величина `sum_i rho_i a_ij` является альтернативной стоимостью сырья: направив
его в производство, предприятие отказывается от возможности продать его по
рынку. Это не обязательно новый денежный платёж поставщику; прежняя цена
покупки уже является понесённой затратой.

Если `c_j < 0`, `A >= 0` и нет требования о минимальном выпуске, оптимальный
план не использует `x_j > 0`: уменьшение `x_j` до нуля освобождает ресурсы и
повышает целевую функцию.

## 3. Контролёр в переменных w

**CONFIRMED — VANDERBEI.** `w_i` — назначенная контролёром стоимость единицы
сырья `i`. Компания должна быть готова продать сырьё внешней фирме по цене,
согласующейся с этой оценкой.

Потерянная альтернативная возможность по запасу `i` равна `b_i w_i`, а общая
потерянная альтернативная стоимость — `sum_i b_i w_i`. Контролёр минимизирует
её, чтобы финансовая отчётность выглядела как можно лучше:

```text
minimize    sum_{i in I} b_i w_i

subject to  w_i >= rho_i                       for every i in I,
            sum_{i in I} w_i a_ij >= sigma_j   for every j in J.
```

Направления неравенств имеют рыночный смысл:

1. `w_i >= rho_i`: иначе внешняя фирма могла бы купить сырьё ниже его текущей
   рыночной цены.
2. `sum_i w_i a_ij >= sigma_j`: иначе внешняя фирма могла бы купить набор
   сырья для продукта `j`, произвести его и продать ниже текущей рыночной цены
   `sigma_j`. Это противоречило бы предположению о преобладающей рыночной цене.

## 4. Замена y_i = w_i - rho_i

**CONFIRMED — VANDERBEI.** Величина

```text
y_i = w_i - rho_i
```

— это надбавка к назначенной стоимости единицы сырья `i` относительно её
рыночной стоимости, а не надбавка к стоимости продукта. Из `w_i >= rho_i`
следует `y_i >= 0`.

Целевая функция преобразуется так:

```text
sum_i b_i w_i
  = sum_i b_i (y_i + rho_i)
  = sum_i b_i y_i + sum_i b_i rho_i.
```

Последнее слагаемое — константа. Она не меняет минимизирующий вектор `y`, но
сдвигает численное оптимальное значение на `sum_i b_i rho_i`.

Для продуктового ограничения:

```text
sum_i w_i a_ij >= sigma_j

iff sum_i (y_i + rho_i) a_ij >= sigma_j

iff sum_i y_i a_ij >= sigma_j - sum_i rho_i a_ij

iff sum_i y_i a_ij >= c_j.
```

Итоговая модель:

```text
minimize    sum_{i in I} b_i y_i

subject to  sum_{i in I} y_i a_ij >= c_j   for every j in J,
            y_i >= 0                        for every i in I.
```

## 5. Общая задача линейного программирования

Пусть

```text
I = {1, ..., m},    J = {1, ..., n},
m = |I|,            n = |J|.
```

Здесь `m` — число ограничений, а `n` — число переменных решения. В
производственном примере они совпадают соответственно с числом видов сырья и
продуктов, но общий смысл именно такой.

Входные данные и переменные:

```text
A = (a_ij)_{i in I, j in J} in R^(m x n),
b = (b_i)_{i in I}           in R^m,
c = (c_j)_{j in J}           in R^n,
x = (x_j)_{j in J}           in R_+^n.
```

**CONFIRMED — VANDERBEI.** Стандартная форма книги:

```text
maximize    zeta(x) = sum_{j in J} c_j x_j

subject to  sum_{j in J} a_ij x_j <= b_i   for every i in I,
            x_j >= 0                        for every j in J.
```

В общей стандартной форме `A`, `b`, `c` — действительные данные. В отличие от
физического производственного примера, отдельные коэффициенты и правые части
не обязаны быть неотрицательными.

## 6. Термины solution, feasible и optimal

**CONFIRMED — VANDERBEI.**

- `solution` — предложение конкретных значений всех переменных решения;
- `feasible solution` — решение, удовлетворяющее всем ограничениям;
- `optimal solution` — допустимое решение, достигающее требуемого максимума.

Задача `infeasible`, если у неё нет ни одного допустимого решения.

Задача максимизации `unbounded`, если у неё есть допустимые решения со сколь
угодно большими значениями целевой функции. Формально, если `F` — допустимое
множество,

```text
for every M in R there exists x^(M) in F such that zeta(x^(M)) > M.
```

Каждое отдельное значение `zeta(x)` для конечного действительного `x` конечно.
Неограниченным является множество достижимых значений, а не одно решение со
значением `+infinity`.

## 7. Эквивалентные преобразования

### Минимизация и максимизация

**CONFIRMED — VANDERBEI.** Для одной и той же допустимой области задачу
`minimize zeta(x)` решают как `maximize -zeta(x)`:

```text
argmin zeta = argmax (-zeta).
```

Если конечные оптимальные значения существуют, они отличаются знаком:

```text
min zeta = -max (-zeta).
```

Преобразование через `1/zeta` в общем случае не эквивалентно: оно меняет порядок
при разных знаках, не определено при нуле и может менять область определения.

### Равенство как пара неравенств

**CONFIRMED — VANDERBEI.**

```text
L(x) = b  iff  L(x) <= b and L(x) >= b.
```

### Slack-переменная

**CONFIRMED — VANDERBEI** для преобразования; **RECONSTRUCTED** для строгого
доказательства. Ограничение

```text
L(x) <= b
```

эквивалентно

```text
there exists a unique s >= 0 such that L(x) + s = b.
```

Доказательство:

- если `L(x) <= b`, то `s = b - L(x) >= 0` и `L(x) + s = b`;
- если `L(x) + s = b` при `s >= 0`, то `L(x) = b - s <= b`;
- равенство вынуждает единственное значение `s = b - L(x)`.

Следовательно, допустимые `x` исходной задачи взаимно однозначно соответствуют
допустимым парам `(x, s)` расширенной задачи. Это доказательство ещё должно
быть самостоятельно воспроизведено учащимся.
